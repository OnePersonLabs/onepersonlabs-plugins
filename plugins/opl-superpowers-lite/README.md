# OPL Superpowers Lite

This plugin contains exactly two skills:

- `systematic-debugging`
- `verification-before-completion`

It preserves the useful debugging and verification disciplines without loading the full Superpowers workflow pack. A recent [r/codex discussion](https://www.reddit.com/r/codex/comments/1uzbpec/does_superpowers_suck_with_56_and_just_eat_tokens/) contains anecdotal reports of increased token use, overcomplicated workflows, and users retaining only debugging or verification. That discussion motivates the lightweight packaging choice; it is community feedback, not benchmark evidence.
