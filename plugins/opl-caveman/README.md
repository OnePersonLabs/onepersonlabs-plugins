# OPL Caveman

Eleven skills imported from the [caveman toolkit](https://github.com/JuliusBrussee/caveman):

- `$caveman`, `$caveman-commit`, `$caveman-review`, and `$caveman-help` shorten responses and offer focused formats.
- `$caveman-compress` compresses supported prose files with an out-of-tree backup. Its script uses the Anthropic SDK or Claude CLI.
- `$investigate-first`, `$lean-build`, `$migration`, `$safe-refactor`, `$surgical-patch`, and `$verify-and-stop` guide focused engineering work.

The skill text and compression scripts are kept with their source material. The plugin adds Codex invocation metadata and marketplace packaging. The upstream copyright and MIT notice are included in [LICENSE](LICENSE).
